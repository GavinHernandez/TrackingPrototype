# TrackingPrototype

## Quickstart Guide for Teammates

### 1. Clone the repo
git clone [https://github.com/GavinHernandez/TrackingPrototype.git](https://github.com/GavinHernandez/TrackingPrototype.git)
cd TrackingPrototype

### 2. Set up Environment
run this in the terminal:
python -m venv venv

#### On Windows:
run this in the terminal:
venv\Scripts\activate

#### On Mac/Linux:
run this in the terminal:
source venv/bin/activate

### 3. Install Dependencies
run this in the terminal:
pip install -r Prototype/requirements.txt

### 4. Run the Code
change line 337 to run the desired video file
run this in the terminal:
python Prototype/trackingPrototype.py

If there is an error with above line, view what folder path is being taken
